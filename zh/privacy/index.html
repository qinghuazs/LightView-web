隐私政策

生效日期 2026 年 10 月 19 日

一句话版本：LightView 不收集、不存储、不传输任何个人数据。没有统计、没有账号、没有联网代码。它做的一切都只发生在你的 Mac 上。

我们是谁

LightView 是一款 macOS 看图工具，由 WANG XINGLEI（"我们"）开发并发布。本政策说明这个 App 如何处理你的数据：除了把你自己的图片显示给你之外，它什么都不做。

LightView 不做的事

  • 不收集任何形式的个人信息。
  • 不使用统计分析、崩溃上报或广告框架。
  • 不包含任何第三方 SDK。
  • 不连接互联网，App 里没有网络代码。
  • 不需要账号或登录。

你打开的文件与文件夹

LightView 会读取你打开的图片以及同一文件夹里的其他图片，以便你浏览。由于 App 运行在 macOS 沙盒中，它只能读取你选择的内容：

  • 你双击、拖入或用 ⌘O 打开的图片。
  • LightView 询问时你明确授权的文件夹，用于显示其中的其他图片。

图片在内存中解码用于显示。缩略图和解码结果只在 App 运行期间缓存在内存里，退出即丢弃。LightView 不会复制、上传或修改你的图片。移到废纸篓（⌘⌫）使用 macOS 标准废纸篓，可以撤销。

存放在你 Mac 上的内容

LightView 在沙盒容器（~/Library/Containers/com.lightview.app）里保存少量偏好：

  • 你的设置，如背景颜色、排序方式、是否显示画廊。
  • 你授权过的文件夹的 security-scoped bookmark，避免重复询问。可随时在"设置 → 文件夹授权"里查看和移除。
  • 窗口大小与位置。

这些数据不会离开你的 Mac。删除该容器文件夹即可彻底清除。

系统权限

macOS 可能会询问是否允许 LightView 访问桌面、文稿、下载文件夹、外置磁盘或网络卷。这些弹窗由操作系统显示；LightView 只用这些权限来列出和显示图片。你可以在"系统设置 → 隐私与安全性 → 文件与文件夹"里更改。

如果某张图片存放在 iCloud 且尚未下载到本机，LightView 会请求 macOS 下载它。该传输由 Apple 的 iCloud 服务按 Apple 的隐私条款处理，与我们无关。

本网站

本站是静态页面，不设置 Cookie，不使用统计分析。下载按钮会向 GitHub API 查询最新版本以显示版本号，GitHub 可能按GitHub 隐私声明记录该请求。若你从 Mac App Store 获取 LightView，商店本身适用 Apple 的隐私政策。

儿童

LightView 不面向儿童，也不从任何人（包括儿童）收集数据。

变更

如本政策有变更，新版本会在本地址发布并更新生效日期。由于 App 不收集任何数据，预计变更会很少。
