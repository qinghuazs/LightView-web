Support

LightView for macOS

Found a bug or have a question? Open an issue on GitHub. Please include your macOS version and the image format involved. Release notes are on the releases page.

Frequently asked questions

Why does LightView ask me to grant access to a folder?

LightView runs in the macOS App Sandbox, so double-clicking an image only gives it that one file. To browse the rest of the folder it needs your permission once. Click "Grant Folder Access", confirm the folder that is already selected, and LightView remembers it. Granting a parent folder covers everything inside it.

How do I revoke access to a folder?

Open Settings (⌘,) and look under "Folder Access". Select a folder and click Remove. The next time you open an image there, LightView will ask again.

The arrow keys do nothing.

Make sure the image window is in front and that no text field has focus. If the status bar shows "Folder unavailable", the disk or folder has gone away; browsing resumes when it is back.

Can I set LightView as the default image viewer?

Yes. In Finder, right-click an image, choose "Get Info", pick LightView under "Open with" and click "Change All".

Undo after moving to Trash says it could not restore the file.

Sandboxed apps cannot reach into the Trash. Open the Trash in Finder, right-click the file and choose "Put Back".

Which formats are supported?

Anything macOS itself can decode: JPEG, PNG, HEIC/HEIF, GIF, WebP, TIFF, BMP, most camera RAW files and more. Animated GIF, APNG and WebP play automatically.

How do I uninstall?

Drag LightView from Applications to the Trash. To remove its settings as well, delete ~/Library/Containers/com.lightview.app.

Privacy

LightView collects no data at all. See the privacy policy.
