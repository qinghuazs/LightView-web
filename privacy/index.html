Privacy Policy

Effective 19 October 2026

The short version: LightView does not collect, store or transmit any personal data. It has no analytics, no accounts and no network code. Everything it does happens on your Mac.

Who we are

LightView is a macOS image viewer developed and published by WANG XINGLEI ("we"). This policy explains what the app does with your data, which is nothing beyond showing you your own images.

What LightView does not do

  • It does not collect personal information of any kind.
  • It does not use analytics, crash reporting or advertising frameworks.
  • It does not include any third-party SDKs.
  • It does not connect to the internet. The app contains no networking code.
  • It does not require an account or sign-in.

Files and folders you open

LightView reads the image files you open and the other images in the same folder so you can browse them. Because the app runs in the macOS App Sandbox, it can only read what you choose:

  • An image you double-click, drag in or open with ⌘O.
  • A folder you explicitly grant access to when LightView asks, so it can show the other images in it.

Images are decoded in memory for display. Thumbnails and decoded images are cached in memory only while the app is running and are discarded when it quits. LightView never copies, uploads or modifies your images. Moving an image to the Trash (⌘⌫) uses the standard macOS Trash and can be undone.

What is stored on your Mac

LightView keeps a small set of preferences in its sandbox container (~/Library/Containers/com.lightview.app):

  • Your settings, such as background colour, sort order and whether the gallery is shown.
  • Security-scoped bookmarks for the folders you have granted access to, so the app does not ask again. You can review and remove them at any time in Settings → Folder Access.
  • The window size and position.

This data never leaves your Mac. Deleting the container folder removes it completely.

System permissions

macOS may ask you to allow LightView to access the Desktop, Documents or Downloads folders, external disks or network volumes. These prompts are shown by the operating system; LightView only uses the access to list and display images. You can change these permissions in System Settings → Privacy & Security → Files and Folders.

If an image is stored in iCloud and not yet on your Mac, LightView asks macOS to download it. That transfer is handled by Apple's iCloud service under Apple's privacy terms, not by us.

This website

This site is a static page. It does not set cookies and does not use analytics. The download button asks the GitHub API for the latest release so it can show the current version number; GitHub may log that request under GitHub's privacy statement. If you get LightView from the Mac App Store, Apple's privacy policy applies to the store.

Children

LightView is not directed at children and collects no data from anyone, including children.

Changes

If this policy changes, the new version will be published at this address with an updated effective date. Since the app collects nothing, we expect changes to be rare.

Contact

Questions about privacy can be raised on GitHub Issues.
